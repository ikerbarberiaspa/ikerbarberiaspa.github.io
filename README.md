# IKER BARBERÍA & SPA

Sitio estático listo para publicar con GitHub Pages.

## Publicación

1. Crea o abre el repositorio `ikerbarberiaspa.github.io` en GitHub.
2. Sube el contenido de este paquete al nivel principal del repositorio. `index.html` y `.nojekyll` deben quedar en la raíz.
3. En **Settings → Pages**, elige publicar desde la rama principal y la carpeta `/(root)`.
4. Guarda los cambios y espera a que termine la publicación.
